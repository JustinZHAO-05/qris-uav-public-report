# Source Notes

This project uses public source anchors for scenario grounding and literature
support. Core communication and optimization results are produced by the local
simulation scripts in `src/`.

| Sentinel-1 | https://dataspace.copernicus.eu/data-collections/sentinel-data/sentinel-1 | SAR all-weather scenario basis |
